### Scenario

<ol>
<li>A 55-year-old patient with early-stage type 2 diabetes needs education to support lifestyle changes and treatment adherence.</li>
<li>The physician prescribes individual education sessions provided by a nurse under the preliminary diabetes care path: four sessions per year, with a maximum of four sessions and no required feedback. The validity ends on 31 December of the year in which validity starts.</li>
</ol>

### Create Prescription

`POST /ServiceRequest`

Profile: [ereferral-servicerequest-nursing](StructureDefinition-ereferral-servicerequest-nursing.html).

Retain the returned ServiceRequest id. Clinical plaintext in the table is represented by encrypted values in the request.

#### Business Values

| Business Field | Value |
| --- | --- |
| Prescription / proposal type | Diabetes education within start trajectory |
| Requested care | Diabetes education within start trajectory |
| Patient | Patient pseudonym: {{SEC1}} / {{transitInfo}} |
| Requester | Physician, SSIN {{prescriberSsin}} |
| Validity start | {{validityStartDate}} |
| Validity end | {{validityEndCalendarYear}} |
| Feedback required | No |
| Educator | Nurse |
| Frequency | 4 time(s) per 1 year |
| Maximum sessions | 4 |
| Education type | Education within a preliminary diabetes care path |
| Session type | Individual |
| Diagnosis / medical problem, before encryption | Early-stage type 2 diabetes |
| Creation date | {{createdAt}} |
