### Scenario

<ol>
<li>A patient with type 2 diabetes has difficulty monitoring her own blood glucose. The physician identifies a need for regular testing to prevent hypoglycemia or hyperglycemia.</li>
<li>The physician prescribes fasting glycemia tests with a glucometer three times a week for two weeks, up to six sessions, without required feedback. The diagnosis is monitoring of known type 1 or type 2 diabetes.</li>
</ol>

### Create Prescription

`POST /ServiceRequest`

Profile: [ereferral-servicerequest-nursing](StructureDefinition-ereferral-servicerequest-nursing.html).

Retain the returned ServiceRequest id. Clinical plaintext in the table is represented by encrypted values in the request.

#### Business Values

| Business Field | Value |
| --- | --- |
| Prescription / proposal type | Glycemia test with glucometer |
| Requested care | Glycemia test with glucometer |
| Patient | Patient pseudonym: {{SEC1}} / {{transitInfo}} |
| Requester | Physician, SSIN {{prescriberSsin}} |
| Validity start | {{validityStartDate}} |
| Feedback required | No |
| Frequency | 3 time(s) per 1 week |
| Treatment period | 2 week(s) |
| Maximum sessions | 6 |
| Glycemia type | Fasting |
| Diagnosis / medical problem, before encryption | Monitoring of known diabetes patients (type 1 or type 2) |
| Creation date | {{createdAt}} |
