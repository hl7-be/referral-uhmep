## Scope

Nursing prescriptions describe requested nursing care and its clinical context. The principal resource is the [Nursing ServiceRequest profile](StructureDefinition-ereferral-servicerequest-nursing.html). Medication preparation under Annex 81 uses the separate [Annex 81 profile](StructureDefinition-ereferral-annex-81.html) and proposal workflow.

## Prescription Types

See [Nursing mappings](mappings-nursing.html) for the business fields, terminology and FHIR representation of each supported prescription type.

The [Test Server scenarios](test-server.html#nursing) currently list the P2M cases provided for integrator testing. M2M cases are not specified yet.
