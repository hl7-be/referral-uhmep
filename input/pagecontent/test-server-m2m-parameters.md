### Scenario

<ol>
<li>A patient with Parkinson's disease has recently been diagnosed with orthostatic hypotension. The physician recommends monitoring blood pressure for posture-related fluctuations.</li>
<li>The physician prescribes blood pressure measurements while lying down, twice a day for one week, up to 14 sessions. Parkinson's disease is recorded as the medical reason and orthostatic hypotension as the diagnosis. Feedback is not required.</li>
</ol>

For M2M, the organization submits creation on behalf of its internal professional.

### Create Prescription

`POST /ServiceRequest`

Profile: [ereferral-servicerequest-nursing](StructureDefinition-ereferral-servicerequest-nursing.html).

Retain the returned ServiceRequest id. Clinical plaintext in the table is represented by encrypted values in the request.

#### Business Values

| Business Field | Value |
| --- | --- |
| Prescription / proposal type | Measurement of parameters |
| Requested care | Measurement of parameters |
| Patient | Patient pseudonym: {{SEC1}} / {{transitInfo}} |
| Requester | Physician, SSIN {{prescriberSsin}}, representing organization NIHII {{organizationNihii}} |
| Validity start | {{validityStartDate}} |
| Feedback required | No |
| Frequency | 2 time(s) per 1 day |
| Treatment period | 1 week(s) |
| Maximum sessions | 14 |
| Parameter | Blood pressure while lying down |
| Diagnosis / medical problem, before encryption | Orthostatic hypotension |
| Medical reason, before encryption | The patient suffers from Parkinson&#39;s disease. |
| Creation date | {{createdAt}} |
