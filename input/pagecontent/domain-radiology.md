## Scope

Radiology prescriptions request diagnostic imaging and carry the procedure, indication, clinical context and supporting information required by the [Diagnostic Imaging ServiceRequest profile](StructureDefinition-ereferral-servicerequest-diagnosticimaging.html).

## Prescription Types

See [Radiology mappings](mappings-radiology.html) for the business fields, terminology and FHIR representation of diagnostic imaging prescriptions.

Radiology Test Server scenarios and their P2M/M2M JSON examples have not yet been specified. Existing radiology artifacts are documented under [Artifacts](artifacts.html) and are not implicitly designated as Test Server cases.
