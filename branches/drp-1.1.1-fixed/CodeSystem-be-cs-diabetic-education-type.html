CodeSystem: eReferral Diabetic Education Type

Official URL: https://www.ehealth.fgov.be/standards/fhir/terminology/CodeSystem/be-cs-diabetic-education-type Version: 1.1.1
Active as of 2026-10-28 Computable Name: BeCSdiabeticEducationType

Types of diabetes education activities.

This Code system is referenced in the content logical definition of the following value sets:

  • eReferral Education Type With Trajectory
  • eReferral Education Type Without Trajectory

This case-sensitive code system https://www.ehealth.fgov.be/standards/fhir/terminology/CodeSystem/be-cs-diabetic-education-type defines the following codes:
