Structures: Resource Profiles

These define constraints on FHIR resources for systems conforming to this implementation guide.

EReferralAnnex81

Annex81 proposal and approval
EReferralImagingAttentionConditionsResponse

eReferral response to the imaging attention conditions questionnaire.
EReferralServiceRequestDiagnosticImaging

The diagnostic imaging profile. eReferral version.
EReferralServiceRequestNursing

The nursing profile, generic version. Please note the nursing referral for medication does NOT depend on this generic version but is a FHIR prodfile on a different FHIR resource (MedicationRequest)

Structures: Extension Definitions

These define constraints on FHIR data types for systems conforming to this implementation guide.

CodeableConcept Extension for Reference

Extension able to hold a coded concept on a Reference element.
eReferral Radiology SupportingInfo Role

Identifies the role of a ServiceRequest.supportingInfo entry used in a diagnostic imaging referral.

Terminology: Value Sets

These define sets of codes used by systems conforming to this implementation guide.

Hybrid SNOMED CT and PSS/QSI Diagnostic Imaging Procedure

Diagnostic care services that can be prescribed for diagnostic imaging using SNOMED CT and PSS/QSI Codes.
PSS/QSI Diagnostic Imaging Procedure

All PSS/QSI diagnostic imaging procedure codes.
PSS/QSI Indication

Indication codes for diagnostic imaging requests as PSS Internal Codes.
SNOMED CT eReferral Supplement Designations

SNOMED CT supplement containing multilingual designations maintained for the eReferral project.
eReferral Imaging Patient Condition Indication

Allowed coded indications for patient condition in diagnostic imaging.
eReferral Radiology SupportingInfo Role ValueSet

Allowed roles for entries in ServiceRequest.supportingInfo in a diagnostic imaging referral.
eReferral/PSS Diagnostic Imaging Condition

Clinical conditions that can support a diagnostic imaging request using SNOMED CT.
eReferral/PSS Diagnostic Imaging Procedure

Diagnostic care services that can be prescribed for diagnostic imaging using SNOMED CT.

Terminology: Code Systems

These define new code systems used by systems conforming to this implementation guide.

PSS Indication

PSS indication codes for diagnostic imaging requests.
PSS/QSI Diagnostic Imaging Procedure

PSS/QSI diagnostic imaging procedure codes with English displays and Belgian French, Dutch and German designations.
SNOMED CT eReferral Supplement Designations

SNOMED CT supplement containing multilingual designations maintained for the eReferral project.
eReferral Designation Use

Identifies terminology designations maintained specifically for the eReferral project.
eReferral Radiology SupportingInfo Role CodeSystem

Identifies the role represented by an entry in ServiceRequest.supportingInfo for a diagnostic imaging referral.
